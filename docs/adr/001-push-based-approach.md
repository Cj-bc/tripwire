# Decision: Pull型ではなくPush型にする
Tripwireに引っかかったかどうかの検出は、pull型ではなくPush型にする。

# why

出来るだけ本来のコンテンツに影響を出さないようにするため。
例えば一定のフェーズ中のみ関係するTripwireは、そのフェーズ内でのみ有効にすることができる。

e.g. 「タイトルフェーズ中にプレイヤーが表示されないべき」というtripwireであれば、「タイトルフェーズへの遷移」を受け取った時に有効化し、他のフェーズへ遷移した時に終了するといったことが出来る。
(フェーズの更新もpushされる前提での話)

一報、pull型にしてしまうと、全てのtripwireを常時舐めにいく必要がある。実際の所そこまで負荷が高くなるかはさておき、出来るだけ動いているものを減らした方が良いという事を考えるとこれは避けられるなら避けたい。

てことは、Coreで行うべきことは「Pushされた情報をUIやLogに配信・記録すること」となる。
